# 🎁 自动福袋助手 v2（免 Root 安卓插件）

基于 **Android 无障碍服务（AccessibilityService）** 的自动参与直播间福袋工具。
不需要 Root、不需要 Xposed，全部使用系统官方无障碍 API。

## v2 相比 v1 的改进

| 改进 | 说明 |
|------|------|
| 🟢 **盲点模式** | 直播间界面多为自绘控件，读不到"福袋"文字时，改为按**屏幕坐标**点击（坐标可在 App 内微调） |
| 🔔 **前台常驻通知** | 把服务提升为前台服务，防止被国产系统一键清理杀掉 |
| 🐞 **调试 Toast** | 每一步在屏幕上弹提示（①已点击福袋 / ②已点击参与 / ③已发送评论 / ④上滑切换），一眼看出卡在哪 |
| 🔍 **关键词扩充** | 参与 / 参与抽奖 / 发表评论 / 领取 等按钮都能识别 |
| 💬 **自定义评论** | 可在 App 内填写自己的评论内容，留空则自动轮换 |

## 自动流程

1. 点击直播间福袋挂件（文字识别优先，识别不到则用坐标）
2. 点击「发表评论后参与」（失败时自动改用坐标点击）
3. 填入评论内容并点击「发送」
4. 上滑切换到下一个直播间，循环往复

内置状态机 + 12 秒超时保护，不会卡死。

## 首次使用步骤（务必按顺序）

1. 安装 `app-debug.apk`
2. 打开 App → 点 **「1️⃣ 打开无障碍设置」** → 找到 **自动福袋助手** → 打开开关 → 弹窗点允许
3. 允许**通知权限**（用于常驻通知保活）
4. 手机「设置 → 电池 / 应用管理」里把本 App 设为：**允许后台运行、允许自启动、不优化电池**
5. 回到 App → 点 **「2️⃣ 开始自动参与」**
6. 打开直播间，观察屏幕上的 Toast 提示

## 坐标校准方法（盲点模式关键）

如果 Toast 显示「未发现福袋」，说明文字识别不到，需要填坐标：

1. 手机「设置 → 关于手机」连续点版本号 7 次打开**开发者选项**
2. 开发者选项里打开 **「指针位置 / Pointer location」**
3. 手动点一下福袋挂件的位置，屏幕顶部会显示 `x`、`y`
4. 百分比计算：**X% = x ÷ 屏幕宽 × 100，Y% = y ÷ 屏幕高 × 100**
5. 把算出的数值填进 App 里对应的输入框 → 点「保存设置」

三个坐标分别对应：福袋挂件、参与按钮、发送按钮。
默认值为常见机型经验值（福袋 10%,12%；参与 50%,62%；发送 85%,88%）。

## 编译 APK

### 云端（推荐，无需安装任何软件）

把本文件夹上传到 GitHub 公开仓库（**必须包含 `.github` 文件夹**），
Actions 会自动编译，完成后在任务页底部 **Artifacts → fudai-auto-apk** 下载。

> 注意：本仓库中工程位于 `FudaiAuto/` 子目录，workflow 里已用
> `defaults.run.working-directory: FudaiAuto` 指定编译目录，不要删掉这几行。

### 本地 Android Studio

`Build → Build Bundle(s)/APK(s) → Build APK(s)`，产物在
`FudaiAuto/app/build/outputs/apk/debug/app-debug.apk`。

## ⚠️ 使用须知

- 仅供学习研究。自动发评论可能违反直播平台用户协议，请**控制频率、轮换评论内容**，账号风控风险自行承担。
- 不联网、不收集任何数据。
- 不同平台/版本界面差异较大，如某一步识别不到，用盲点模式配合坐标校准解决。
